Claude Session Hub · Unread UI 备选 v0.12 改进方案

4 个方向并排对比 + 现状 baseline。每个方案都包含：sidebar 顶部全局聚合区 + 4 条 session（active / unread+waiting / unread / 普通）。

A · 数字脉冲徽章 渐进改良

保留现有数字徽章但加红色脉冲呼吸动画 + 顶部全局聚合 pill；卡片背景换成淡紫 tint（去掉刺眼绿色）。

  • 改动最小，不破坏老用户肌肉记忆
  • 顶部 "5 unread" 一眼看出还有几个未读
  • 红色脉冲解决"提示太弱"
  • 仍有数字（"3" vs "30" 行为相同）
  • 红 + 紫 + 蓝 + 橙四色并存

B · 极简红点 极简党

去掉数字徽章，只用 8px 红色脉冲圆点 + 顶部精确数字总数。强调"有/无"而非"多少"。

  • 视觉极简，零干扰
  • sidebar 折叠时不挤占标题宽度
  • 类似微信 "@" 提及但已读：人类直觉熟悉
  • 失去"多少条新消息"信息（可在 hover tooltip 补回）
  • 红点 + waiting 黄 badge 仍同行

C · 紫色沉浸式 v0.9 主题派

未读卡片整体染紫（与 Hub v0.9 紫色基调对齐），左侧紫色发光边 + 渐变背景。徽章用紫色 chip 而非红数字，统一色系。

  • 跟 v0.9 紫色基调完全统一，最美观
  • "unread 卡片" 一眼可识别（整卡片高亮 vs 角落小徽章）
  • 颜色冲突最少：紫为 unread 主色，红留给真异常
  • 紫色与 selected（蓝色）对比稍弱，需要测
  • 大量 unread 时整列紫色可能"花"

D · 左缘脉冲带 视觉冲击派

未读卡片左缘伸出独立 3px 紫红渐变发光竖条 + 呼吸动画；卡片本体几乎不变。极小角徽 14px 圆 + 数字。

  • "扫读最快"——余光也能看到呼吸条
  • 不动卡片本体颜色，密集列表不混乱
  • "等你" + "未读" 视觉分离最干净
  • 动画呼吸长时间可能视觉疲劳
  • 需调 sidebar 左 padding 给条留位置

UI 问题：
  • 四色冲突：selected=蓝边 / has-unread=绿边 / is-waiting=橙边 / unread-badge=红
  • "卡片背景变绿"信号弱（--session-active=#1c2d1c），跟 --session-selected 区分度低
  • waiting + unread 同行：橙黄 badge + 红 badge 颜色硬碰
  • 无全局聚合：顶部不知道几个 session 未读
  • 无 in-app 提醒动画：unread→read 切换"啪"消失

顺手要修的后端逻辑（与 UI 解耦，独立施工）

  • renderer.js:3754（silence fallback）补 document.hasFocus() 检查，与 hook 路径行为对齐 — 修 #1
  • renderer.js:4407 当 isActive && document.hasFocus() 时确实不 bump，但 active session 后台默默写新 turn → 用户未真正"看到" → 加 "page visibility + 用户最近 ≥30s 无 input" 二级 guard — 修 #6/#10
  • 新增 IPC get-global-unread-count（renderer 聚合 sessions Map）+ topbar 显示 — 支撑 4 个方案的全局聚合区
  • 给 .unread-badge 加 transition: opacity .2s, transform .2s 让消失更柔和 — 修 #8
  • 持久化层（state.json）已经持久化 unreadCount（session-manager._toPublic），无需改动
