# 上下文优化 · 2026-10-05

目标是减少重复说明和不适用的流程，保留授权、证据、完整数据、提交确认与单 writer 等边界。文字变短不等于模型质量已经提高；判断质量仍需同模型、同任务的行为验证。

## Hub 共用变更

- 群聊默认聊天正文与 Markdown 表格，HTML 按用户要求或实际使用价值选择；所有后端使用同一入口。
- 已送达群规则保存内容指纹。规则更新或上下文压缩后，下次真实派发补发一次；失败不推进回执。投委会静默游标不被当成规则送达，避免每幕重复规则。
- 助理每轮保留短契约，兼容压缩与后端切换；Codex 799 字符、其他后端 776 字符。冻结快照、hash 核对、来源引用、原会话路由、审批、confirmed/unknown 与关注回执保持。完整工具输出仍需读取，截断时扩大本次预算补读；保留服务端输出上限。
- research 场景保留用户确认的交易纪律，明确只用于具体交易决策；结论采用正向证据要求。
- Codex 请求窗口按所选账号的模型目录上限约束。旧 Sol 的 1M 偏好保留为请求，已知上限较小时先收敛；新模型继续原生默认，未知目录交由 CLI 判定。启动与重启共用解析器，真实有效窗口仍以原生回执为准。
- 根 AGENTS 保留常驻边界；细节与事故操作留在 `agent-operations.md`。Claude 的导入入口共用这份规则。

## 配套共享配置候选

候选、修改前 hash 与逐文件备份清单位于任务 worktree `artifacts/20261005-context-opt-codex1/`。应用前核对所有文件 hash，保存备份，再同步全局规则到所有登记的 CLI 原生入口。账号或个人配置中出现独立修改时保留并报告冲突。

- 个人规则由 `.agents/USER_CONTEXT.md` 统一维护；按需要核对共享记忆，避免每个任务重复读两个索引。原生记忆库内容保持原样。
- `huawei-ppt`、`gen-ppt-image`、`content-research-writer` 入口压缩为阶段路由，完整操作拆入 references；保留候选选择、模板保存、provider lock、材料与来源 gate。Claude 与 Codex 的共享目录或镜像同步。
- `agent-reach` 触发限于专用平台访问需求；普通检索走宿主原生能力。
- Codex 默认/second 账号禁用与共享目录内容相同的 `channel-sim` / `superran` 副本；文件与源项目保持。
- 生图 MCP 公共说明压缩，队列、重试、取消授权及部分交付说明保留；细节沿用生图 Skill。两类客户端的 MCP 入口指向同一安装源。

已有会话不能删除历史上下文。原生规则、Skill 目录及 MCP 元信息需新会话/重载才读取新版；群规则可以在升级后下次派发补发。运行中的生产 Hub 不由本任务重启，程序改动在下次启动加载。

## 验证与保留项

有状态规则投递检查首次、更新、失败重试、旧回执迁移与静默游标；快照检查冻结与篡改拒绝；模型窗口检查两个账号不同目录和未知模型。
隔离 Hub 的真实 Codex/Claude 验收覆盖交接、派工、关注、后端切换与重启恢复。合入由正式入口执行全量单测并抬版本。

暂不改 SuperRAN 源 Skill 正文、原生记忆协议、默认安全/预算 gate 或模型原生系统提示。原生工具可能按需暴露，MCP 说明减少量不能直接算成每轮 token 节省；不以文字缩减宣称质量提升。
