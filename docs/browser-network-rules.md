# 专属 Chrome 与网页工具的网络规则

适用范围：Hub 账号页，以及使用 `HubChrome` 的网页工具、AI 圆桌和人工验证入口。2026-10-01 根据本机故障与复测整理；当前节点的快慢属于运行证据，不能当作永久配置结论。

## 网络入口

- 专属 Chrome 的国外请求使用当前 Hub 代理配置；国内 AI 和已确认的配套域名按照 `core/hub-browser-routing.js` 直连。域名按完整边界匹配。
- 代理配置变更后核对运行浏览器的路由记录。已有网页或任务时提示先保存并关闭，下一次启动应用新配置；不能把新配置当作旧进程已经生效。
- 日常 Chrome 是否使用 Clash，需要分别检查 Windows 系统代理、Clash 系统代理/TUN 与浏览器代理参数。Clash 有规则不等于浏览器请求已经进入 Clash。
- 通过 Clash 请求时，再核对规则实际选中的节点；主站和验证服务都要检查。读取控制器凭据只在进程内使用，日志和报告不能包含密钥或订阅 URL。

## 人工操作与登录

- 账号页和人工验证入口使用不带调试端口的普通 Chrome；与自动化模式共用账号资料和 Hub 分流。
- 切换前检查浏览器占用，保护已有标签页、草稿与任务。人工窗口仍开着时，工具提示用户关闭窗口后再继续；不能用租约到期替代真实关闭。
- 保存登录资料。验证循环的处理只涉及相应站点的验证 Cookie；清理前确认需要，操作后单独核实登录。磁盘 Cookie 存在不等于当前网页已登录。
- 工具遇到真人验证时退出验证页面并暂停对应站点。人工完成后再恢复；提问送达不确定时先核对原会话。

## 性能取证

- 左下角的毫秒数来自 Clash 所选节点的健康检查历史，附测量时间。它说明探测请求的延时，不说明持续下载速度，也不说明到 ChatGPT、Claude 的真实加载耗时。
- 文件探测记录 URL、时间、HTTP 状态、首字节与总耗时、传输字节、压缩和 HTTP 协议。短文件的“字节/总耗时”包含连接等待，不能当作线路最大吞吐。
- Windows 自带 curl 的功能因版本而异。本机复测时它仅支持 HTTP/1.1，而 Chrome 使用 HTTP/2；curl 未指定 `--compressed` 时，脚本可能比浏览器下载的大数倍。
- 比较普通配置与 Hub 配置时，用相同 Chrome、相同资源、相同缓存策略，交替测试并记录实际路线。新临时资料的测试只证明网络配置差异；真实账号页另行验证，不清空真实资料来制造冷启动。
- 报告分别说明已完成下载、页面出现输入框、提问送达、最终回答和真人验证状态。取消或未完成的请求不计作成功下载；Cloudflare 测速服务的结果不能独自代表 AI 网站。
- 同次排障若同时重启、调整扩展或清理验证状态，记录这些变化，不把恢复归因于单一动作。过去的慢速与当前的快速度都保留，注明时间和测量条件。
