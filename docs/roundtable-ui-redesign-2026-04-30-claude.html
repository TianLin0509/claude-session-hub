圆桌 UI 重设计 · Claude 提案

基于 core/roundtable-scenes.js 统一架构（2026-04-30 已落地），针对当前 UI 挑出 4 个最高 ROI 的改进点。每条都给出 BEFORE / AFTER 视觉对比 + 决策依据。

P0-1 三家颜色统一：Panel ↔ Feed ↔ Avatar 一套 token 最值得做

当前同一个 AI 在 UI 不同位置颜色不同，最严重的是 Gemini 在 rt-card 是蓝色 (#1a73e8)，在 feed 里是紫色 (#7c3aed)， 一眼就觉得"乱"。建议每家定一个权威色 + 透明度梯度，全栈统一。

P0-2 卡片思考态：从"角落徽章脉冲"到"卡片主体呼吸" 最高情绪价值

当前 thinking 状态只有右上角一个小徽章在闪，卡片主体仍展示上一轮的旧回答。 用户敲完 @debate 等 25 秒，眼睛根本不知道盯哪儿——"它到底在不在动"。 建议思考态时整张卡片明显"在工作"，最好能流式显示思考片段（即使是 streaming 中的前几句）。

P0-3 顶部加"轮次进度 + 可用命令"导航条 解决发现性问题

当前用户得自己记住 @debate / @summary @claude / @gemini 私聊内容 这些语法。新用户进来根本不知道有这些能力。建议在顶部用按钮形式暴露， 且根据当前轮次状态智能高亮"下一步建议做什么"。

认知模型升级： 从"用户必须先读文档才会用"→"用户能在 UI 里被引导发现能力"。 这是新功能能不能被持续用起来的关键 —— 不被发现的功能等于不存在。
P1 刚创建的圆桌：从"空白终端区"到"示例引导卡" 首次体验

当前用户点 "🎯 创建圆桌" 后看到的是空白终端 + 顶部 "首次发送较慢（约 25 秒）" 一行提示。 第一印象=空荡荡。建议 0 轮时用一个 onboarding 区填充示例问题， 用户点示例 = 自动填进输入框；同时把 25 秒提示做成可视化进度条而非一行小字。

我的建议落地顺序

  1. P0-1 色彩系统统一（半天）— 最基础，做完后续改动都建立在统一 token 上
  2. P0-3 顶部命令栏（1 天）— 解决发现性问题，圆桌价值能不能传达全靠这条
  3. P0-2 卡片思考态（1.5 天）— 工程量最大但情绪价值最高，让 25s 等待不再难熬
  4. P1 onboarding（半天）— 锦上添花，首次体验更友好

可以暂不做的： 重做整体配色 / 加深色浅色主题切换 / 重构 layout（focus mode 已经很好）/ 改终端区域 — 这些 都是大改动小收益。核心要打的是"发现性 + 等待感"两个用户痛点，不是颜值。
