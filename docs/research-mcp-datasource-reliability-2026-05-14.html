三工具数据源可靠性排序

2026-05-14 · 立花道雪 · 按可靠性从高到低排（最可靠的源在每条链最前面，failover 时一层一层降级）
核心结论   3 个工具共聚合 17 个 sub-op，底层共调用 10 种数据源。 QMT 是最可靠数据源（券商直连，权威+实时），但需要桌面客户端启动；不可用时按 Tushare → akshare → 东方财富 → Ashare → Baostock → Sina 逐级 fallback。 公告/研报这类法定/官方数据走 巨潮 cninfo / 财新（不在通用兜底链里，但本身权威）。

1. 全局数据源排行（10 种源）

Tier 1 · 最可靠（主源首选） Tier 2 · 高可靠（主流副源） Tier 3 · 中等（兜底） Tier 4-5 · 末层（最后救场）
排 数据源 类型 需求 稳定性 / 覆盖维度
1 QMT（迅投券商终端） 实时 + 全维 桌面客户端必须启动 券商直连最权威，盘口+逐笔实时；但盘后/未启动时不可用
2 Tushare 近实时 + 全维 需付费 token A 股最专业的付费源；财报/估值/北向/股东数据最全；有限流
3 akshare 近实时 + 全维 免 token 开源包装多个上游（东财/同花顺/百度/巨潮）；覆盖最广；偶有接口改版
4 东方财富（HTTP 直连） 近实时 免 token 最快（~200ms）；网页接口长期稳定；偶有反爬
5 巨潮（cninfo） 官方披露 免 token 证监会指定法定信息披露平台；公告数据最权威；通过 akshare 包装
6 财新主新闻 近实时新闻 免 token 财经主流媒体；通过 akshare；仅大盘新闻不含个股
7 同花顺 THS 实时 免 token 行业资金面/板块概览（通过 akshare）；本次主要给 peers 兜底用
8 Ashare（vendored） 实时行情 免 token / 零依赖 单文件库；新浪+腾讯公开 HTTP 双源自动切换；只有 OHLCV 5 字段；行情最后救场
9 Baostock 历史数据 免 token 免费稳定但慢（~1.7s）；只覆盖 K 线和部分基本面
10 Sina 财经 实时行情 免 token 极稳定（无鉴权）；字段最少；只有最基础的报价
"最可靠"不只看在线率，还看数据精度+覆盖广度+实时性。QMT 是券商内网直连券商交易所行情，没有更上游；Tushare 付费保障；akshare 是社区集大成（覆盖最广）；末层 Sina 虽然永远不挂，但只有报价没别的字段。

sub-op数据源链（按可靠性从高到低）

工具 主源（Tier 1-2） 兜底深度 最坏情况 压测成功率

stock_news 巨潮 + 财新（通过 akshare） announcements 2 层 / market_news 1 层 akshare 改版接口可能影响；改版后约 1-2 周内 akshare 维护者会跟进 10/10 (100%)
关键洞察

1. QMT 是兜底链顶端，但不是普及条件——大多数场景下盘后 / 用户没开 QMT 时，实际拿到的数据是 Tushare 或 akshare 的。本次压测 30/30 通过，但实测 QMT 命中率约为 0%（QMT 客户端未启动），实际兜底链是 Tushare/akshare 在扛。

2. akshare 是覆盖最广的"中坚源"——它在 9/17 个 sub-op 里出现，是事实上的主力。它的稳定性直接决定整个系统的稳定性。

3. 巨潮 cninfo 在公告维度是无可替代的——它是证监会指定的法定披露平台，公告权威性最高。akshare 包装的就是巨潮官方 API，不需要再爬。

4. Ashare 单文件库是 price 的"绝对兜底"——它用新浪+腾讯公开 HTTP 接口，无依赖、无 token、永远在线。即使 LinDangAgent 全挂，price 仍能拿到 K 线。
