# 初心 Agent 联赛 P0 · 日频决策、Hook 与周六沉淀

更新：2026-08-27

## 当前口径

- 原生初心投研 `Agent 联赛` Tab，不是 iframe 或独立网页。
- 每个 Agent 是一个普通、可恢复的 AI Hub Session，可直接打开卡片和 PTY。
- 初始模拟资金 ¥500,000；沪深 A 股全市场，不含北交所。
- 佣金买卖双边万分之一；卖出印花税千分之一；不设置最低佣金与额外滑点。
- 系统不替 Agent 判断单票、总仓位或现金风险；只检查目标权重闭合并机械执行账户约束。
- 主板/创业板买入按 100 股整数倍；科创板单笔买入至少 200 股、超过 200 可按 1 股递增。
- P0 不做盘中决策。

## 每个交易日

```text
08:30 读取冻结数据并输出 DRAFT
  ↓
同一个普通 Session 逐条执行 CHECKLIST Hook
  ↓
锁定 FINAL + 300-500 字 DAILY_BRIEF
  ↓
09:35 按当日开盘价机械执行
  ↓
15:10 记录收盘净值与结果
```

Hook 只调用一次，包含：规则一致性、最强反证、时机、组合风险自判、行为偏差和账户可行性。结果为 `PASS / REVISE / HOLD`。

每日文件保留 DRAFT、Hook、FINAL、短文、开盘执行和收盘结果。若 Hub 中断，已写入阶段不会消失；失败 Agent 可在同一日期单独重跑。若错过开盘执行，下一次决策前会尝试从初心历史日 K 恢复该日开盘价，失败时拒绝覆盖旧 pending。

## 周六

同一个 Session 读取最近交易日记录，区分过程与盈亏，向 `MEMORY.md` 增加一条待验证经验，并可向 `EVOLUTION.md` 提出最多一条 `CHECKLIST.md` 修改建议。提案不会自动生效，`AGENT.md` 不变。

- 理念：价值投机；基本面与产业逻辑决定方向，估值与位置决定赔率，催化、资金和走势决定时机。
- 当前标记为“第一版建议策略，待创建者确认”。
- 自动赛程关闭；Session 尚未创建；模型尚未调用；没有模拟订单。

## 提示词工作台

Agent 详情提供“查看 / 编辑全部提示词”：

- 可编辑：`AGENT.md`、`STRATEGY.md`、`CHECKLIST.md`、`PROMPT_DAILY.md`、`PROMPT_HOOK.md`、`PROMPT_WEEKLY.md`、`AGENTS.md`、`CLAUDE.md`、`GEMINI.md`；
- 只读感知：`MEMORY.md`、`EVOLUTION.md`、`SESSION.md`、`PORTFOLIO.md`、`TRADES.md`、`STATS.md`、提示词编辑历史；
- 系统合同预览：盘前 DRAFT、决策 Hook、周六沉淀的完整编译 Prompt。

编辑正文时机器状态单独展示并受保护；保存使用 SHA-256 乐观并发检查、原子替换和历史备份。`CHECKLIST.md` 保存时会同步解析规则 ID。下一次自动任务直接读取新版本。
