# 初心 Agent 联赛 P0 · 日频决策、Hook 与周六沉淀

更新：2026-08-28

## 当前口径

- 原生初心投研 `Agent 联赛` Tab，不是 iframe 或独立网页。
- 每个 Agent 是一个普通、可恢复的 AI Hub Session，可直接打开卡片和 PTY。
- 初始模拟资金 ¥500,000；沪深 A 股全市场，不含北交所。
- 佣金买卖双边万分之一；卖出印花税千分之一；不设置最低佣金与额外滑点。
- 系统不替 Agent 判断单票、总仓位或现金风险；只检查目标权重闭合并机械执行账户约束。
- 主板/创业板买入按 100 股整数倍；科创板单笔买入至少 200 股、超过 200 可按 1 股递增。
- P0 不做盘中决策。

## 每个交易日

```text
08:30 读取冻结数据并输出 DRAFT
  ↓
同一个普通 Session 逐条执行 CHECKLIST Hook
  ↓
锁定 FINAL + 300-500 字 DAILY_BRIEF
  ↓
09:35 按当日开盘价机械执行
  ↓
15:10 记录收盘净值与结果
```

Hook 只调用一次，包含：规则一致性、最强反证、时机、组合风险自判、行为偏差和账户可行性。结果为 `PASS / REVISE / HOLD`。

每日文件保留 DRAFT、Hook、FINAL、短文、开盘执行和收盘结果。若 Hub 中断，已写入阶段不会消失；失败 Agent 可在同一日期单独重跑。若错过开盘执行，下一次决策前会尝试从初心历史日 K 恢复该日开盘价，失败时拒绝覆盖旧 pending。

## 周六

同一个 Session 读取最近交易日记录，区分过程与盈亏，向 `MEMORY.md` 增加一条待验证经验，并可向 `EVOLUTION.md` 提出最多一条 `CHECKLIST.md` 修改建议。提案不会自动生效，`AGENT.md` 不变。

## 第一位 Agent

生产数据根已初始化 `chuxin-baseline / 初心基准`：

- 理念：价值投机；基本面与产业逻辑决定方向，估值与位置决定赔率，催化、资金和走势决定时机。
- 当前标记为“第一版建议策略，待创建者确认”。
- 自动赛程关闭；Session 尚未创建；模型尚未调用；没有模拟订单。

## 提示词工作台

Agent 详情提供“查看 / 编辑全部提示词”：

- 可编辑：`AGENT.md`、`STRATEGY.md`、`CHECKLIST.md`、`PROMPT_DAILY.md`、`PROMPT_HOOK.md`、`PROMPT_WEEKLY.md`、`AGENTS.md`、`CLAUDE.md`、`GEMINI.md`；
- 只读感知：`MEMORY.md`、`EVOLUTION.md`、`SESSION.md`、`PORTFOLIO.md`、`TRADES.md`、`STATS.md`、提示词编辑历史；
- 系统合同预览：盘前 DRAFT、决策 Hook、周六沉淀的完整编译 Prompt。

编辑正文时机器状态单独展示并受保护；保存使用 SHA-256 乐观并发检查、原子替换和历史备份。`CHECKLIST.md` 保存时会同步解析规则 ID。下一次自动任务直接读取新版本。

## 交易日历

自动赛程使用上交所公布的 2026 年休市安排，覆盖到 2026-12-31。覆盖期外会明确暂停，不会静默退化成“周一到周五都开市”。下一年度安排公布后更新日历即可。

手动“盘前决策”表示为下一次开市准备：周末、法定休市日或当日 09:15 截止后点击时，会按官方日历自动定位下一交易日。调用方显式传入错误的非交易日仍会拒绝，不会静默改写。

顶部动作名为“全体盘前决策”：一次点击会把当日尚未完成的全部 Agent 加入同一赛程，并按最大并发数自动运行或排队，不需要逐个重复点击。运行中按钮保持可点击并改为“查看决策进度（N）”；先选择排行榜中的 Agent，再点击该按钮即可打开对应 PTY。排行榜状态按真实阶段显示 `DRAFT 中`、`Hook 中` 或 `周复盘中`，不再把尚未生成 native SID 的运行中 Agent 误标为“待首次运行”。

## 虚拟实盘调试

联赛页顶部“虚拟调试”进入独立沙盒：

- 正式联赛根保持不变；沙盒固定在正式根的 `_virtual_debug/` 子目录；
- Agent 身份与可编辑提示词从正式联赛复制，但 Session、DRAFT/Hook、持仓、成交、统计、快照和赛程全部重新建立；
- Session 标题以“虚拟 Agent ·”开头，并使用独立 `purpose=agent-league-virtual` 和 `agent-league-virtual-*` MCP scope；退出调试不会删除沙盒，重置只删除经过路径守卫确认的 `_virtual_debug/`；
- 虚拟时钟从下一官方交易日开始，严格按“盘前决策 → 开盘执行 → 收盘记账 → 下一交易日”推进；后端也拒绝跳阶段，不只依赖按钮禁用；
- 分化、普涨、普跌、窄幅四种行情均为确定性合成数据。开盘阶段不会提前泄漏虚拟收盘价；推进日期时全候选池继承上一虚拟收盘价；
- 盘前 DRAFT 与 Hook 仍调用真实绑定 AI Session。虚拟模式禁止引入快照外股票、禁止调用真实行情，输出和正式排行榜完全隔离；
- “运行账本自检”不调用模型、不写联赛文件，在内存中覆盖买入、主板/科创申报单位、现金、pending 清除、同日收益基准、卖出印花税和清仓八项不变量。

账本日收益以“上一交易日收盘净值”为基准；同日开盘执行写入的中间净值会在收盘时被替换，不能成为当日收益分母。首个交易日以初始资金为基准。

Codex 初次启动若出现 PowerShell 已显示完整启动命令但换行被粘贴处理吞掉，联赛只在尚无 native SID 时发送隔离 Enter 恢复；已经进入 Codex TUI 的 DRAFT/Hook 不受该恢复逻辑干扰。
