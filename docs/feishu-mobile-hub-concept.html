把 Claude Session Hub 变成飞书里的多 AI 圆桌助手

手机端不再打开 PWA 或远程终端，而是在飞书里直接和 Hub 机器人对话。 电脑继续负责运行 Claude、Gemini、Codex 和本地项目环境；飞书负责提问、通知、圆桌卡片、追问和审批。

远程盯进度 手机收到任务开始、模型完成、卡住、等待确认和最终总结，不需要盯着电脑终端。
及时介入 看到某个模型跑偏，可以直接点“追问 Claude”或发送 @debate，让 Hub 继续组织下一轮。
保留圆桌优势 手机输入一个问题，Hub 在电脑端拉起多模型圆桌，飞书只呈现观点卡和总结卡。
1. 手机提问

在飞书私聊或指定群里输入“圆桌：问题”，也可以用快捷按钮新建任务。

2. Hub 接管

本地 gateway 收到消息，创建会议室或普通 session，绑定飞书 thread。

3. 多 AI 输出

Claude、Gemini、Codex 独立回答，飞书收到进度和观点卡片。

4. 手机决策

一键追问、辩论、总结、允许工具调用，必要时再回电脑深度操作。

可以做哪些功能

P0

飞书圆桌入口

发送“圆桌：问题”后，Hub 自动创建会议室，拉起 Claude、Gemini、Codex，并把每个模型的结果整理成飞书卡片。

P0

进度通知

任务开始、模型完成、卡住、失败、最终总结都推送到手机；你不用打开电脑确认任务是否还在跑。

P0

工具审批

当 AI 等待权限确认时，飞书发审批卡。手机点“允许一次 / 拒绝 / 只读允许”，Hub 写回对应 session。

P1

追问与辩论

每张观点卡提供“追问此 AI”“@debate”“@summary”按钮，也支持直接在飞书输入命令。

P1

会话状态面板

发送“状态”即可返回当前运行中的 session、未读、最近输出、是否等待输入、是否可继续。

P1

轻量新建任务

在飞书里指定项目目录和任务目标，Hub 在电脑端创建普通 session 或圆桌 session，手机只负责调度。

P2

语音/图片输入

飞书语音转文字、图片 OCR 或文件上传后转成 Hub prompt，适合路上快速记录想法。

P2

日报与回放

每天汇总今天问过的问题、各模型结论、最终采纳意见和未完成任务，沉淀到 Hub Ledger。

P2

多渠道扩展

飞书先跑通后，再把同一套 HubCommandRouter 接到企业微信、微信或专用 APK。
