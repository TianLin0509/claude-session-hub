⑤ 风险与边界条件

场景处理策略
头像图片加载失败img onerror fallback 到 emoji（🟡/🟠/🔵）
token 信号缺失（Gemini 部分场景）显示 "本轮 -"，不写入累加器
累计数据持久化state.aiStats 随 state.json 持久化（已有 _saveState 机制）
preview 区文本超长flex: 1; overflow: hidden 自动截尾，CSS 控制不破坏布局
会议室主区窗口缩小220px 固定高度 + 三列等分仍然成立；极端情况（窗口 < 480px）可触发响应式降级到单列
头像动画影响性能仅 transform: translateY，GPU 合成，3 个元素无压力
