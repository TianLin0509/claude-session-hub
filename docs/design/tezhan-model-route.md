# 家里按模型给公司派活（GLM / DeepSeek 分流，2026-10-18）

田哥：号池里两个号（自己的、同事的）分别能用 GLM 和 DeepSeek；家里的 Agent 自己判断用哪个模型，简单任务交给 DeepSeek，工作日白天给同事们常用的 GLM 分流。

## 链路

1. **公司 → 家里「模型表」**（`core/codeagent-model-route.js` `modelTable`）：个人账号 + 号池可用的号按模型聚合：模型名、能用的号数、通道在处理几个、还能并行几个（每号忙时 / 闲时上限 × 能接的号，再受通道整体上限约束）、是否忙时、哪个是日常主力（GLM 一族）。不含账号名、工号、备注。配对后（含公司 Hub 重启后）推一次；之后模型集合、号数、忙闲或「还能并行」的档位（0 / 1 / 2+）变了才推，最快 10 分钟一次；每份回执、以及「指定模型没有可用的号」的报错也带一份。
2. **家里存下**：数据库一份，通道目录 `company-models.json` 一份。MCP 列工具时现读它，`ask_company` 的描述末尾带模型表和选择原则；没有时写「模型表未知」。命令行 `company-ask.js models` 看同一份，`ask --model` 指定。
3. **家里 `ask_company` 的 `model`（可选）**：模型表已知时必须是表里的（大小写不敏感，按表里写法发），否则报错并列出可选项、不发出；未知时只核对格式，由公司核对。不填 = 公司默认，与以前完全相同。
4. **公司按模型开会话**：在有该模型权限的号里挑（进行中会话少的优先，其次不用切模型的，再次号池优先，最后轮转）。没有哪个号有它 → 不开会话，回执写明原因和可选模型；有权限的号都在跑别的模型或到了每号上限 → 排队，只等有该模型的号空出来，不占别的问题的名额。追问沿用原会话；会话休眠后恢复仍按原模型（`codeagentRouteModel` 随会话持久化）。
5. **界面**：特战会话名不变（`1018-Q1-codex`），CodeAgent 卡片显示所用模型；通道串、家里「问公司」列表和公司「AI特战队专用功能」的任务列表显示指定 / 实际模型。设置里没有新开关。

## 怎么让会话用上指定模型（取舍）

- **为什么通道会话原来不传 `--model`**：公司 CodeAgent 交互模式不认 `--model`（2026-10-13 真机三轮排查：启动画面写着 MiniMax，回答仍是 GLM；`--settings`、环境变量、`/model <名字>` 也不生效，只有 `-p` 一问一答认）；能用的只有 `/model` 菜单，但它在公司真机上把第一条消息卡住约 1 分钟（2026-10-15 田哥反馈），所以通道会话一律用号的默认模型、不走菜单。
- **选的路径**：号配置目录 `settings.json` 的 `model` 决定新会话的模型——2.1.8 起号池同步配置就靠它把 DS 号定到 DS（修「DS 号报找不到 GLM」），`/model` 菜单按回车也是把默认模型存进这里。不触发任何菜单，也不在命令行加不生效的参数。
- **号池的号**：Hub 管它的配置目录。默认模型就是指定模型的直接用；两个模型都有的号，只有它上面没有进行中的会话时才切（CodeAgent 可能在会话中重读设置，切了会影响正在跑的会话），切之前的模型记在 `hub-route-model.json`，之后不指定模型、号空闲时换回，不指定时的行为不变。
- **个人账号**：号主自己日常用的配置，不切；只有它此刻的默认模型就是指定模型时才用它（个人账号 GLM、号池同事号 DS 的组合正好覆盖田哥说的两个号）。
- **不静默换模型**：挑不出号时不退回个人账号或别的模型；回执另记 `requestedModel` / `actualModel`（回答里实际出现的模型），不是同一家时家里提示里明说。

## 审核后的补充（2026-10-18）

- 隐私：通道会话（purpose=company-bridge）的号池报错只写「号池里的一个号」，哪个号只记本机日志；公司一端发回家里的 `status` / `reply` / `hub-admin-status` 里的说明与报错再统一脱敏（号池编号、工号掩码、备注、显示名，以及掩码样式兜底）。
- 「能用」只算真能派的号：个人账号只算它此刻的默认模型，不在表里列它切不过去的模型，指定了也直接回「没有可用的号」；号池号一直有会话、切不过去的，最多等 10 分钟，超时回原因和「现在可直接用的模型」。
- 不指定模型时，挑号避开「为通道切过模型、上面还有会话」的号；只剩它时照用（或恢复到这样的号），回执元数据写实际模型（`codeagentLaunchModel`）。
- 「CLI 没就绪」「等切模型」的起算时间不跨进程沿用，新进程第一次重试从头算。
- 家里模型表未知时指定模型，`ask_company` 返回提醒可能不生效；回执里公司没确认指定模型（旧版）或没从回答里确认实际模型时如实写。
