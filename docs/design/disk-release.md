# 硬盘释放

2026-10-04，候选功能；尚未合入生产。

## 需求与操作

C 盘曾达到约 98%，大量空间被旧的隔离测试数据、下载缓存和 Android 测试设备占用。底部「硬盘」百分比现在是独立入口：点击打开清单，勾选项目，查看确认页，再明确确认清理。CPU / 内存入口继续打开原有内存释放面板；两块面板互斥。

后台扫描有可见进度，清理后报告执行前后真实磁盘可用空间的变化，以及每项完成或保留的原因。清理中关闭面板不会中断删除，再次打开能查看进度和结果；扫描中关闭会取消扫描。清理回执保存在 Hub 数据目录的 `disk-release/`。

## 可清理范围

- 用户临时目录中，名称符合已知 Hub / 助手 / 投研测试前缀且带隔离数据标记的旧测试目录。最近 48 小时有更新的保留。
- npm `_cacache` 和 pip `cache` 下载缓存，保留已安装的程序和 Python 环境。
- `C:\VibeData\Temp` 内按日期命名的 Android 测试设备。需要手动勾选，确认页说明虚拟设备及其登录状态会删除。

这是指定位置的清理器，不是全盘文件删除器。正式聊天历史、登录配置、源码、系统文件、开发环境不作为清理目标；包含 `.git`、`node_modules`、`.venv` 或目录链接的测试目录整项保留。活动进程引用目标、开发进程身份不可确认、依赖安装正在进行、模拟器正在运行时，相关项目保留。

## 删除边界

扫描与实际删除在 Worker 中执行。文件路径通过 JSON 输入交给隐藏 PowerShell，禁止拼接成命令。预计空间通过 Windows `GetCompressedFileSizeW` 核对实际占用，避免把模拟器稀疏文件的逻辑长度算成可释放空间。Windows 进程枚举可能留下已退出进程且命令行为空的瞬时记录，额外核对进程是否存在，仅剔除已确认退出的 PID；进程仍存在或访问受限时继续保留相关数据。

扫描产生十分钟有效的私有清单；执行只接受本清单的随机 key 和明确确认，不接受调用方传入的删除路径。执行前重新检查活动进程、整个文件清单、大小、更新时间与文件身份。逐个删除前再次检查真实目录边界、祖先链接和文件身份；文件变化或检查失败时保留。只逐文件 unlink、空目录 rmdir，不穿透 junction。Windows 命名管道实现跨窗口清理互斥，崩溃后由操作系统自动释放。

空间变化可能受其他程序同时写盘影响，因此最终显示磁盘净变化，而不是承诺一定释放预计大小。扫描采用进程信息和更新时间判断使用状态，不替代 Windows 文件锁；被占用且不能删除的文件保留并报告。

## 验证

`node --test tests/unit-disk-release.test.js`：20 项，包括确认、未知路径拒绝、文件变化、活动进程、源码、junction、真实 Windows 占用核对、过期清单和跨窗口锁，以及已退出进程与访问受限进程的区别。

`node tests/e2e-disk-release-panel-cdp.js`：后台隔离 Hub 内真实鼠标操作，完成打开、确认、真实删除测试数据、保留扫描后变化文件与外部文件、结果展示、内存入口互斥、键盘及关闭操作。截图中的 5 MB 清理数据为专门构造的测试数据。

本机另做默认位置的只读扫描，证据在 `artifacts/20261004-disk-release-readonly-real-codex2.json`；这次扫描未删除用户文件。全量验证使用项目入口 `node scripts/run_unit_tests.js --jobs 2`，674 个文件全部通过，完整日志为 `artifacts/20261004-disk-release-unit-all-final-codex2.log`。首次全量有两项既有测试因终端 PATH 缺少 `sh.exe` 失败；只在最终测试进程的 PATH 加入 Git 的 `bin` 目录后完整重跑，不修改系统配置。
