# 启动中心：整组默认配置

2026-10-14 用户要求：红框内账号、模型、思考强度、速度通道和 MCP 全部由一次“设为默认”保存，下次创建一起恢复；整理未对齐的表单。

## 原因与用户影响

2026-09-23 的 `82060360` 只引入默认模型。按钮只比较模型，其他字段使用内存中的临时选择；速度改变后仍可能显示“默认”，重启后也无法恢复完整配置。这是原有能力范围不满足整组默认的需求。

## 行为

- 每类 AI 独立保存可用的字段。模型继续写入 `models.defaults` 兼容旧配置，其余写入 `launch.defaults`；同一次读、校验、写入，不覆盖其他配置。
- 新打开启动中心时恢复已保存的整组值；同一轮在提供方间切换保留草稿；关闭后未保存的草稿不替代默认。
- Codex 的“本次会话账号”作为启动参数传入，不在改选或保存默认时修改全局账号。账号页的全局切换、旧会话恢复和显式重启仍保留原有路径。
- Claude Fast 的 true/false、Codex 的 inherit 均作为明确值保留。无对应能力的 AI 隐藏控件；PowerShell 隐藏整块配置。
- DeepSeek 接入方式也纳入整组默认。旧接入配置仍作为未保存时的兼容初值。
- 模型目录异步刷新不覆盖用户已修改的选择。不可用的旧默认值在表单上直接提示；保存失败保留当前选择并显示可重试错误。

## 布局

沿用 Hub 主题变量和原生选择控件。整组保存按钮移到配置标题旁；Codex 上排账号与模型、下排强度与速度及 MCP，所有控件高 38px。目录三列等宽，窄窗口自动换行。详细说明折叠，错误与影响选择的警告保持可见。保留左侧新建、群聊、恢复入口。
