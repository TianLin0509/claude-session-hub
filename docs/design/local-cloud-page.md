## 可见行为

- 机器 CPU、内存、磁盘、在线进程组由现有 SSH 连接按需采集。默认页面可见时 5 分钟刷新；支持 15 分钟和纯手动。关闭页面、窗口隐藏时暂停定时采集。请求合并、超时有界；失败保留上次成功快照并标明时间。
- 列出已盘点的 23 个服务入口、用途、进程组 CPU/工作集、网址、部署位置。13 个应用后端与 Caddy 分开；10 个静态入口共享网关，不分摊伪造独立占用。进程运行与网页/登录后业务健康明确区分。
- 搜索、筛选、内存排序、收藏、详情。网址由主进程按目录 ID 打开；公司收件箱的私密 URL 从已有服务器路由按需读取，不持久化或返回给 renderer。
- 一键优化先只读扫描，再显示确切候选文件、规则与已知收益，用户点击执行后才改变远端文件。只处理允许目录中超过 7 天的顶层 `.tmp/.temp` 临时文件，和超过 7 天、明确轮转命名的历史日志。单次最多 50 个、每个最多 10 MiB。当前日志、业务数据、更新安装包不参与。
- 删除前重验规范路径、目录/文件重解析点、大小、修改时间和硬链接，通过同一独占句柄完成验证与删除。日志先写 gzip，验证解压 SHA256 一致且确有节省，再删除原文件；已有压缩文件不覆盖，半完成时校验一致后继续源文件删除，冲突时保留两份并报告失败。每项失败继续，结果独立记录；结果不确定时重新扫描而不假装成功。
- 维护记录显示确实执行的结果；备份未接入时明确未知。验证真实云端只进行刷新与只读扫描；写入行为在本轮新建的隔离文件夹中验证，不为测试清理真实服务器。

## 实现与回归

不新增依赖或常驻远端代理。主进程 IPC + 有超时的 OpenSSH + 固定 PowerShell 程序；使用已登记 SSH key 和严格主机密钥核验，不读出 key。任何来自 renderer 的路径或 shell 文本均不接受。

保留其他 Tab 的导航、会话草稿、生产进程、在途文件、既有服务器设置。新增模块随 community export 的 drop/strip 同时排除，覆盖公司目标。合入由独立审查后走 `scripts/merge_task.py` 自动升版本、全量测试与推送；不重启生产 Hub。

验证包括：刷新去重、过期/错误缓存、数据异常与停止服务、静态共享资源、过期/伪造优化计划与重复点击、真实 PowerShell 隔离文件行为、公开/公司导出、真实隔离 Electron 导航与云端只读采样。截图和证据写任务 artifacts。

`node tests/e2e-cloud-page-cdp.js` 默认使用明确标注的模拟数据，实际点击和键盘操作页面；`HUB_CLOUD_LIVE=1` 才读取本机已登记 SSH 连接，并在主进程强制只读。两种模式都使用隔离数据与后台窗口。真实服务器验证覆盖采样和扫描，执行流程由模拟 GUI 与真实隔离文件夹测试分别覆盖。

文件删除使用 Windows 的 [SetFileInformationByHandle](https://learn.microsoft.com/en-us/windows/win32/api/fileapi/nf-fileapi-setfileinformationbyhandle)，先取得 DELETE 权限，完成校验后在原句柄上设置删除标记，避免释放锁后再按路径删除的竞态。
