# 团队私人入口（2026-10-24）

团队页面连接的是林田个人部署的阿里云站点，不能作为公司全员默认入口。公司发行配置仅表示包含功能，不代表允许访问。

- 所有版本的团队按钮初始隐藏，避免首屏闪现。按 Ctrl+Alt+T 打开本地密码对话框，输入独立私人口令；不复用 AI 特战队邀请码或旧隐藏入口口令。
- 主进程使用 scrypt 校验摘要和恒定时间比较。明文不进仓库、安装包、日志或浏览器存储。连续错误五次暂停尝试一分钟。解锁只在内存有效，每次重启重新锁定。
- 团队数据 IPC、操作 IPC、网页打开，以及后台 Workspace 都检查授权。未解锁不启动团队定时器，不创建网页 AI 工作者，不加载团队网站。
- 锁定停止团队定时器，销毁团队网页（先提示未提交内容风险），取消网页 AI 任务。已有网页登录态和本地持久数据保留。
- 公司助理中带 teamOwner 标记的团队分析也检查授权。锁定取消排队任务、中断运行中的团队回合，拒收迟到结果；助理页面隐藏团队聊天，重试同样受限制。普通助理任务保留。

## 验证

单测覆盖错误口令、限速、重启锁定、异源 IPC、未解锁读写/网页拒绝、后台延迟启动、团队助理排队和运行中的取消、普通助理不受影响，以及网页 claim 返回前锁定的竞态。真实隔离公司版使用鼠标与键盘验证快捷键、错误/正确口令、页面打开、手动锁定和同一数据目录重启。

## 边界

这是一道正式 Hub 的本机功能访问限制，不是对电脑管理员或修改源码者的安全隔离，也不是企业身份认证。持有口令的人可以解锁，故专用口令不得向员工分发。阿里云网站的直接 URL 访问仍由网站自己的登录与权限控制；本改动不声称对公网网站增加了服务端鉴权。已生成的本地文件、原生会话历史不加密。

本轮未发布安装包、未部署云端、未修改生产 Hub 数据或进程。
