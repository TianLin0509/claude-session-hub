# 公司版会议伴侣 · 4.1.0

入口：助理 → 会议伴侣。两部分通过同一会议时间线衔接：持续采集、本地转写与独立 CodeAgent 会议理解。采集不等待模型返回，成功保存理解与游标后才推进处理范围。

## 保留的功能

简报、WeLink 查询、手机对话、PPT 素材库、会议室守护继续沿用现有服务。会议会话单独创建，不占助理串行队列，不挂助理会话控制 MCP 或家里联动 MCP。原有生产 Hub 不重启。

## 采集

用户选择窗口或屏幕，可按百分比裁出 PPT 区域。每秒观察画面，稳定且内容变化后保存 JPEG；少量新增文字采用变化像素比例补充平均差判定。手动补截图、重点标记一直可用。完全相同截图复用文件，保留再次展示事件。

系统声音与麦克风分别采集，PCM16 WAV 每 15 秒落盘；暂停、结束刷新末段。录音起点使用同一单调时钟。默认 16 kHz 单声道，每路约 115 MB/小时；两路约 230 MB/小时，加截图。当前选择 PCM 便于可靠离线识别，不宣称压缩音频的 59 MB 估算。

写盘失败暂停采集，未写片段留在内存，可重试。断开画面后不能继续假采集。运行中离开助理页仍然采集；关闭 Hub 前需结束会议。意外退出后，已保存的会议标为中断，剩余转写与理解可继续，未满分段且未落盘的音频可能损失。


## 4.1.0 连续录制、回放与按需取证

复用 Chromium MediaRecorder，不新增编码器依赖。捕获所选完整来源（15 fps 上限），录像采用 VP8/Opus、目标视频码率2.5 Mbps；原图截图仍按用户裁切范围保存。系统声音和麦克风混合进回放音轨，同时保留原有双轨WAV供识别。按目标码率估算视频约1.17 GB/小时，实际受内容和编码器影响，另外有原双轨WAV及截图；界面显示实际累计大小。

每30秒开启独立WebM分段，前后重叠500ms；每秒收到的编码块追加到对应分段文件并fsync。MediaRecorder timeslice块不能当作独立视频（W3C https://www.w3.org/TR/mediastream-recording/），只有同一recorder完整组合后才作为ready片段回放。追加按字节偏移核对，重试不重复追加。正常暂停和结束刷新尾块；异常退出保留已完成片段，未完成片段标为interrupted、不宣称可完整回放。时间线使用单调时钟，暂停明确留空，不压缩真实会议时间。

主进程按会议编号和分段索引产生本地媒体URL，播放器不通过base64搬运整场视频。用户按全场时间选择片段，播放结束自动接续下一片段；跳过暂停时明确提示。主进程用独立隐藏视频窗口按需解码最多6帧，默认最长边受1280×1080约束，清晰局部上限1920×1080。衍生截图保存在本场目录，原视频保留。

每场部署skills/meeting-companion/SKILL.md，并在每轮prompt明确读取。meeting-only MCP提供meeting_index、meeting_read和meeting_frames；独立token绑定会话身份，参数不选择其他会议。返回标准image内容而非base64文字；索引和转写分页，取图有数量限制。此范围限制仅作用于会议工具，不是CodeAgent文件系统沙箱。普通助理hub_sessions与家里桥接不挂给会议会话。

底线：连续录制不等于绝对无损。来源选择、操作系统采集、设备断开、掉帧及磁盘错误可能造成缺口；UI保留可核对范围。未运行真实公司会议时，不能用合成音视频或Claude替身验收宣称原生公司会议闭环已测。

## 本地识别（沿用4.0.0）

按需在数据目录建立独立 Python venv，固定 faster-whisper 1.2.1，下载 Systran/faster-whisper-small；CPU int8、两线程。首次安装需要组件和模型下载能力；没有 Python 时从 python.org 下载独立嵌入式运行时，不改系统 Python。模型安装后本地离线识别。公司无此下载条件时需要预置组件，目前不把联网安装成功当作公司端已就绪。

常驻子进程串行识别 WAV，使用 NumPy 直接解 PCM，避免 PyAV 版本兼容引发读取失败。模型未安装或识别错误不删除原始音频，界面显示原因并支持重试。音轨不是说话人身份，纪要不推断姓名。

## 理解与恢复

每 60 秒按增量事件更新；显式提问、手动更新、结束后全部转写完成触发整理。每批最多 120 个事件，余下继续处理；传入前一版摘要及最近发言，允许按需只读完整会议文件。独立 session 使用原生 promptOperations 与 LiveHistory。

派发前持久化 batch 范围、原生回答基线、唯一回执 token。只接受带当前 token 的新最终回答，原子保存摘要、游标和版本。未确认派发不自动重送；超时保留材料并提示检查后重试。会话创建 await 之后重读会议，避免覆盖并行采集。

每版理解保存 understanding-N.json。关键结论引用事件，区分建议、已确认、未明确、被后续修订。原始材料不是指令，不执行材料中的命令或会后工作。

## 验证范围

单测覆盖去重、末端 WAV 格式、转写与游标、旧回执拒绝、并行采集、恢复、路径约束和小幅文字变化。真实隔离 Hub 的 CDP 测试覆盖入口、布局、来源枚举、合成画面/音源经真实 IPC 落盘与回看。物理麦克风、真实会议软件音频、公司 CodeAgent 后端需独立现场证据，不能以合成流替代。
