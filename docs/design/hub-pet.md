# 助理桌宠（2026-10-16）

田哥选定的设计稿：`D:\AI-Artifacts\20261016-助理桌宠设计-claude1.html`。助理以桌面小宠物的形式出现：平时安静待在屏幕角落，有提醒就欢呼并说一句，点它打开 Hub 的助理页。公司版默认开，家里自用版默认关，「配置 → 助理桌宠」可开关、换角色、调说话频率。

## 借鉴 WorkMate（C:\AIWork\20260908-WorkMate-Pro，美术版权归田哥）

| WorkMate 里的做法 | Hub 里怎么用 |
|---|---|
| 6 个角色、每个 4 张姿态图（待机、敲键盘、欢呼、打盹），猫和企鹅另有 25 帧的生活小动作、敲键盘、贴边、伸懒腰序列 | 原样沿用，转成 WebP（单图 320 px，序列拼成 5×5 图每格 250 px，全部 2 MB）。帧序列按第一帧与对应单图的外框对齐、脚底重合，交叉淡入时角色不跳；顺手清掉了原帧顶上残留的上一格脚底细边。转换脚本 `scripts/build-hub-pet-assets.py`。 |

| EdgeBehavior 贴边 190 ms cubic-out | 照搬；贴边按「身体」算，窗口两侧透明部分可以伸出屏幕。 |
| NodOffDirector：犯困点头 2.4 s → 惊醒 0.5 s → 深垂 1.8 s → 睡着 | 照搬时长，用连续变换演完再淡入打盹图；醒来时猫和企鹅播伸懒腰序列，其他角色用拉伸 + 小跳。 |
| AnimationPolicy：常态靠连续呼吸，离散帧只给有意义的动作；待机手势 28–45 秒一次，稀有表演 240–420 秒 | 照搬节奏；没有生活序列的 4 个角色改用歪头、小跳、挤一下三种连续动作代替。 |
| MeetingRadar（会议时躲开） | 先只做全屏检测（Windows 自带的「勿扰」判断 SHQueryUserNotificationState）；按会议时间躲开要等助理页的日程数据。 |
| QuietCompanion 安静 30 分钟 | 改成右键「安静一小时」「今天别说话」与设置里的安静档。 |

改进点：

1. **更顺**：WorkMate 的帧动画是逐帧硬切；这里帧序列按时间插值（相邻两帧按小数部分叠加），姿态之间 220 ms 交叉淡入，旧图层晚一点淡出，中间不露底。拖动时向移动方向倾斜、按速度拉长，拎起来放大 5%、影子缩小。
2. **更省**：只有在动（跳、回弹、淡入、播序列、拖动）时每帧刷新；只剩呼吸时降到 20 帧/秒，打盹 12 帧/秒；窗口不可见时整个循环停下。只改 transform / opacity / background-position，不触发排版。隔离实测空闲时桌宠渲染进程约 0.2%、GPU 进程约 0.2–0.3%。
3. **不糊**：所有图都按 1.5 倍以上的像素准备，125% / 150% 缩放下不放大位图。
4. **融入 Hub**：说的话来自共享提醒总线 `core/company-assistant/notice-bus.js`，助理忙不忙看助理会话本轮是否在跑（CLI hook 状态），点它把 Hub 拉到前台并发 `hub-pet:open-assistant`。

## 行为

- 姿态优先级：全屏 → 躲边探头；正在说话 → 欢呼；助理会话本轮在跑 → 敲键盘；10 分钟没操作，或 19:00 后、7:00 前 → 打盹（夜里点它一下醒一分钟）；额度低（留了 `hub-pet:signal` 入口）→ 有点累；其余待机。
- 说话：提醒一次一句，8 秒后收成小圆点（显示条数），点气泡或小圆点展开正文，「在助理里打开 ›」带上提醒的 id 与会话 id。每小时最多开口 3 次；安静档、安静一小时、今天别说话、全屏、打盹时只亮小圆点。温和档只说提醒，活泼档再加早上问候、离开半小时回来打招呼、连续坐 90 分钟提醒。
- 右键：今天的会、下午会前准备、谁在等我回、汇总某个群、未读邮件分拣、起草周报（发 `hub-pet:open-assistant`，带 action 和默认问题）；安静一小时、今天别说话、说话频率、换角色、收起桌宠。

## 在线形象与升级（2026-10-17 / 10-18）

- 公司版只带小猫、企鹅；兔子、柴犬、仓鼠、玄凤在「助理 → 设置 → 桌宠」里在线下载（`core/hub-pet/role-packs.js`：catalog + 形象包，逐个核对字节数与 SHA-256，GitHub `hub-pet-v1` 与阿里云 `/hub-update/hub-pet/` 依次试）。平时只在用户点「下载 / 检查新形象」时联网。
- 例外（2026-10-18 用户批准）：设置里记着的形象是可下载的已知形象但这台电脑上没装（2.1.8 选了兔子等、升级到 2.1.9 的用户），桌宠启动后在后台用同一条校验下载路径补装，装好当场换上、不打扰；下载失败只说一次温和提示（白天是气泡，夜里/安静档是小圆点），点开「在助理里打开」直接到「助理 → 设置 → 桌宠」。每次启动最多试一次；用户期间自己换了形象就不提示。
- 记着的形象没装时显示先用小猫，但设置文件里一直保留原来的选择（不再因为任何一次别的设置写盘被改成小猫）。

## 给助理页的入口

渲染端 `window` 上会收到 `hub-pet:open-assistant` 事件，`detail` 为 `{ source: 'pet', action?, prompt?, noticeId?, sessionId? }`。助理页自己决定是切页、打开某条提醒还是把 prompt 填进输入框。
