Hub sidebar + 代码块 浅色风备选 2026-05-10

说明

4 个备选都是把左侧栏 + 代码块从深色变成浅色风。每个方案下面用同一段对话场景演示真实信息密度。每个方案区别主要在两点：

  • sidebar 底色：纯白 / 微浅灰 / 冷蓝灰 / VibeChat 原版分割线风
  • 代码块底色 + 高亮配色：GitHub light / 极简浅灰 / 米色暖调

所有方案保持 user 气泡微信绿、AI 气泡白底（vibechat-light 主题已落地的部分不变）。

方案 A · sidebar 纯白 + 代码块 GitHub Light

sidebar 用纯白底 #ffffff，hover 浅灰 #f3f4f6，选中带微信绿左侧色条 + 浅绿底（与 user 气泡同色系）。代码块用 GitHub light 风 #f6f8fa + 经典 GitHub 高亮配色（红 keyword / 深蓝 string / 棕 number）。最贴近 VibeChat 原版的纯白 IM 风。

📂 styles 改造 · session-2026-05-10-01
帮我看下 renderer/styles.css:2731 的 .turn-card，能不能把 user 卡片左侧那条紫边改成更柔和的样式？

CLAUDE · 14:22

方案 1 最不破坏现有视觉：

.turn-card.user {
  background: var(--turn-bg-user);
  border-left: none;
  background-image: linear-gradient(90deg,
    rgba(167,139,250,0.18), transparent 28px);
}

这样保留紫色提示，但从硬边变成 28px 渐隐，质感更柔。

方案 B · sidebar 微浅灰 + 代码块 极简浅灰

sidebar 微浅灰底 #f9fafb（不刺眼），hover 弹起到白色 + 微阴影；选中是白卡 + 紫色左侧条。代码块用极简浅灰 #fafafa + 紫色 keyword + 绿 string + 棕 number 配色（更接近 hub 既有紫色调）。最低对比度，最柔和。
