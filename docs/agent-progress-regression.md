# 2026-10-23 卡片进展与公司通信回归

用户要求：各 Agent 已公开输出的思考与进展带时间直接显示，不按语言过滤、不默认折叠；模型筛选单列各 Agent；公司通信标识常驻且可查看交互历史。

保留的边界：最终答案、工具记录、原生完成信号、会话归属与分页不改变。只展示实际原生文本，不解密隐藏推理；记录没有独立时间时沿用其所属原生消息时间。

根因与修复：

- 共用卡片曾将进展放入默认关闭的过程区；现在进展直接显示，工具仍在工具区。
- Codex 磁盘过滤遗漏 reasoning，DeepSeek 的公开 reasoning_text 因此丢失；Kimi 仅识别 text 而遗漏 think。逐条投影保留时间和稳定身份，清空流式缓冲同时清空思考，避免带入下一轮。
- Antigravity、Gemini、旧 Claude 与 Codex 原生后端合并思考时丢失逐项时间；现在在合并前生成带时间的显示消息。
- 全量回归还复现了 Antigravity 两份快照修改时间相同时旧完整记录覆盖实时新记录；同时间明确以实时快照为准，截断字段仍从完整记录补齐，并用固定相同文件时间的用例防复发。
- 模型筛选曾只有 Claude/Codex/其他；现在从 AI 注册表生成并按发行版筛选，DeepSeek 各后端同属一项。
- 公司通信状态只读取全局最近 60 条，旧会话因此丢标识；现在按会话读取本地数据库完整历史，包含归档。旧请求不能覆盖新状态；打开历史不发送请求、不恢复会话。

验证入口：

- `node scripts/run_unit_tests.js`：全量单测。
- `node tests/e2e-agent-progress-cdp.js`：隔离 Electron、原生转录及 SQLite 夹具；验证进展默认可见、中文长文本、时间、筛选、旧通信常驻、弹窗全文、状态与刷新。
- `node tests/e2e-simple-chat-cdp.js`：本地 App Server 协议夹具，回归真实发送路径、增量、复制、长回答及工具详情。
- `node tests/e2e-antigravity-history-cdp.js`：12 轮历史，首次 8 张、加载 24 张、追加后 26 张，稳定 ID、会话切换和刷新。

以上 GUI 用隔离数据和后台窗口，不代表已发布或已重启生产 Hub，也不代表向真实云端模型或公司侧发起过新请求。
