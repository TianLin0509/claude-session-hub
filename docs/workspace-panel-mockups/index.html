Workspace 面板 · UI 风格 3 备选
点击任一卡片预览完整 mockup · 3 个方案使用同一套假数据，方便横向对比
面板定位：Hub 内嵌的只读信息面板。核心目的是让用户快速看到「几个 Claude 在干什么、有没有撞车」。
假数据场景：4 个活跃会话 · 1 个硬碰撞（两个会话同时改 renderer/diary-view.js，且共享 hub-diary worktree） · 1 个分支级软冲突 · 1 个 package.json 依赖告警。
OPTION A
仪表盘卡片风
白底 + 灰阶 + 状态色。会话卡片网格布局，顶部红色告警条，最稳重。Hub 现有 UI 风格延续，长时间盯不累。
日常监控 信息密度中 对外可秀
OPTION B
作战指挥室
黑底霓虹 + 等宽字体 + 雷达脉冲。三栏：会话花名册 / 拓扑图（节点连线显示碰撞）/ 实时事件流。碰撞极度醒目。
高警觉 视觉冲击强 短时盯盘
OPTION C
矩阵热力图
核心是「会话 × 文件」二维矩阵 + 热力色阶。同一列出现两个深色格子 = 碰撞。下方时间线辅助。数据感最强。
数据驱动 碰撞自然涌现 需要理解矩阵

横向对比

维度A 仪表盘B 指挥室C 矩阵
碰撞醒目度中（红条 + 卡片描边）极高（雷达脉冲 + 闪烁）高（红格脉冲，但需扫矩阵）
信息密度中高极高
视觉负担低，可长时盯高，盯久眼累中
新会话扩展卡片自然增长左栏列表 + 拓扑节点矩阵增加一行
「会话×文件」可视卡片内文件列表事件流时序为主矩阵原生支持
