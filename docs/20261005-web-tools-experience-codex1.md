# 网页工具与账号页体验优化候选

网页登录工具在 VPN 故障后留下旧失败记录，生图常驻客户端又使原绑定路径变化。账号页因此可能提示连接变化，而调用者难以判断订阅生图是否仍可用。

本候选识别登记入口到常驻生图客户端的受管连接链，核对身份、共享浏览器根和入口来源；账号页分别显示 Codex 订阅生图健康、网页兜底历史状态与检查时间。默认读取本地记录，不启动浏览器、不检查全部网站、不导入 Cookie。

圆桌只支持当前已实现的 DeepSeek、Kimi、千问。状态接口展示每家进度、错误代码和下一步，支持最多 20 秒的等待查询。额度用完与限流、登录、验证分开显示。Hub 对受阻圆桌任务提供“复核并继续原任务”：必须取得对应主身份、对应网站的新鲜官方登录证据；已发送问题只收原回答，原会话未知则保留任务并报告恢复错误。网页生图任务仍由原 Claude/Codex 会话检查账号后调用 `image_resume`，避免账号页批量接管其他人的队列。

配套生图插件候选 0.7.32 在独立仓库：空闲网页车道按需启动，无任务 60 秒后退出；显式账号操作、网页兜底和仍需定时观察的原任务保留唤醒能力。修复没有网页账号时拒绝纯订阅任务的问题，并同步 MCP、CLI、Skill 的启动提示和版本。未测量整机资源收益，不报告 CPU/RAM 节省比例。

## 验收证据

- 真实 Claude 使用显式候选 MCP 配置：订阅生图完成一张，保存原图并看图确认；DeepSeek、千问首轮和同会话追问都成功，持久记录确认追问 URL 没变；Kimi 返回 `quota_exhausted`，首轮保留两家完整答案，部分结果和追问均生成报告。
- 中转固定会话只读检查得到已登录、页面就绪。未发送消息，未执行 pull/ack，未推进读取游标。
- `node tests/e2e-account-center-cdp.js`：真实隔离 Hub 的鼠标、键盘、窄屏、绑定保存、原任务恢复失败提示均通过；网站和授权操作使用夹具。真实网站结果单独取证。
- `node --test tests/unit-web-tools-experience.test.js tests/unit-web-roundtable.test.js tests/unit-web-login-recovery.test.js tests/unit-hub-accounts-workspace.test.js` 56 条通过；最新相关 18 条再次通过。
- 生图 CI 的全部本地脚本通过，包含队列 22、可靠性 33、吞吐契约 561、恢复 34、人机验证 20、Codex 回退 66 条；账号契约含一个既有跳过项，协议检查和发布文件扫描通过，Skill 校验通过。
- Hub 全量命令为 `node scripts/run_unit_tests.js`；详细结果和本轮失败诊断写入 `artifacts/20261005-hub-full-unit-codex1.log`，不得由上述聚焦检查替代。

## 生效边界

此分支与插件都尚未合入或部署。插件部署须保留机器专用 `.mcp.json`、真实队列、登录资料与配置，等待在途任务安全结束后替换版本；旧 MCP 会话需重新加载。Hub 版本由项目合并入口抬升，不为验证重启生产 Hub。

主号 ChatGPT 固定会话登录正常不等于网页生图端到端成功；副号网页兜底本轮未重新生成验收。旧海报/周报、通用浏览器及更多 AI 网站没有逐站验证，也没有新增 ChatGPT/Gemini/Claude 圆桌适配器。
