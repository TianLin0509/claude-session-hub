03数据接入实现(Plan AB)

Hub 设置加一个 "PackyAPI Cookie + User ID" 输入区,有则升级到完整版,无则降级显示"今日/累计"消耗。

新增配置项(Hub 设置 → PackyAPI 段):
  • packy_session_cookie — 整段 cookie 值(从浏览器 cookies.txt 拿,你提供的那种)
  • packy_user_id — 可自动从 cookie 解出(我已实测可用 — gob 解码 session payload 拿 id 字段),用户不需要填
实现路径:
  • 新增 core/packy-balance.js — 封装 cookie 解析 + balance 拉取 + 缓存
  • 定时刷新:5 分钟 一次,缓存到 ~/.claude-session-hub/usage-cache.json 的 packy 段
  • UI 不阻塞 — 启动直接显示缓存值,后台静默刷新,刷新完成发 IPC 让 renderer 重渲染
  • Cookie 过期 → 显示 "余额: 重新登录"(不是 error,只是黄色提示)+ 设置入口
Cookie 安全提示:整段 session cookie 写到本地 config.json,Hub 数据目录权限是 user-only,但仍要让你知道这等同于你的浏览器登录态 — 有人拿到这文件就能登录你的 packyapi 账户(直到 cookie 过期)。
缓解:
  • Hub 配置文件不进 git(已经 .gitignore)
  • cookie 过期时间 (timestamp 1780237503 → 2026-08-31) 我会显示在设置里,提前一周提醒你刷新
