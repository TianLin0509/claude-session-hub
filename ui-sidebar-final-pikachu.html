03PackyAPI 数据怎么拿 — 你二选一 关键决策

实测了 PackyAPI 的所有候选端点。余额必须用 access token(网站 console 个人设置生成),普通 sk- key 拿不到。

Plan A · 完整版 推荐

显示余额 + 月消耗(像你截图那样)。需要你做一次性 30 秒配置:

  • 去 www.packyapi.com/console 个人设置生成 system access token
  • 粘贴到 Hub 设置(我会新增一个 "PackyAPI Token" 输入框)
  • Hub 用该 token 调 /api/user/self,拿到 quota / used_quota
  • 每 5 分钟刷新一次,缓存到 ~/.claude-session-hub/usage-cache.json

实现成本:配置项 + 一个 fetchPackyBalance() 函数 + 缓存逻辑,~80 行。

Plan B · 简化版 立即可用

只显示月消耗,不显示余额。零配置,Hub 自动用现有 sk- key 查:

  • 调 /v1/dashboard/billing/usage?start_date=...&end_date=...
  • codex 组 + bailian 组 两个 key 各查一次,加和
  • 实测 codex 组本月 $21.26 + bailian 组 $0.88 = $22.14

缺点:看不到余额,不能做"快充值"预警(快花光了你不知道)。

我推荐 Plan A:你截图里专门强调了 $29.67 余额这个数字,说明你最在意的就是剩多少钱。Plan B 只能告诉你"花了多少",回答不了"还能花多久"。
