This is a visual proposal only. It keeps the current product idea: a dense Electron workspace for terminal sessions, preview panels, and multi-agent meeting rooms. The expected improvement is stronger information hierarchy, clearer session triage, and fewer controls competing with the terminal.

1. Sidebar triage

Promote waiting/running/unread into filters and cards. This reduces the cost of finding the next session that needs action.

2. Stable context header

Group cwd, model, state, and next action above the terminal. Avoid hiding critical metadata in transient terminal text.

3. Inspector instead of overlays

Use a predictable right-side inspector for preview, memo, risks, files, and decisions so the terminal does not get visually crowded.

4. Meeting operations board

Separate agents, timeline, and decisions. The user should see who is streaming, who is done, and what decision remains.
