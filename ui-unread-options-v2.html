Unread UI v2 · 6 个无数字标识备选 基于 B 方向 + 你的偏好

需求：去掉数字徽章、统一标识（不论 1 条还是 30 条都一样视觉）、无全局聚合数。

每列 sidebar：① active session（蓝边） ② unread + waiting（同时） ③ 仅 unread ④ 普通无未读

B1 · 极简红点（脉冲涟漪）

9px 红色圆点 + 涟漪动画，贴在 status-dot 之后。waiting 仍走橙色 "⏸ 等你" badge，与红点共存。

  • 跟你 B 方案最接近，零数字干扰
  • 红色脉冲在余光范围内可被瞥见
  • 红点 + 橙色 waiting badge 仍同行（红橙并列）

B2 · "⏸ 等你" 统一标识 推荐

把 "⏸ 等你" 这个用户已熟悉的 token 升格为唯一未读标识。waiting 用橙色保持现状（紧急）；普通 unread 也用相同 "⏸ 等你" 但红色版（不紧急但有新消息）。

  • 语义最统一：waiting/unread 视觉同形，仅颜色分级
  • 用户已熟悉的图形，无学习成本
  • 红/橙色区分"紧急 vs 一般"自然
  • 红橙仍是 2 色（但语义清晰）
  • "⏸ 等你" 文案对纯 unread 略重（可选其他文案如"新"）

B3 · status-dot 染色（结构最干净）

不加新元素，把现有的 session 状态点直接染成红色 + 脉冲。waiting 染橙色脉冲。已读则恢复绿色（idle）/灰色（dormant）。

  • DOM 不增加节点，渲染最轻
  • 状态点变色最贴近"灯亮了"直觉
  • 不动右侧 badge 区，不挤标题宽度
  • session 状态（idle/running）信息被覆盖（unread 优先）
  • 跟 favicon-style 提醒一致，但相对低调

B4 · 左缘红条（强冲击）

未读 session 左缘伸出 3px 红色发光竖条 + 呼吸动画。waiting 时改橙色。selected 仍用蓝色 left-border（互不干扰，红条贴卡片外侧）。

  • 扫读最快，余光也能看到
  • 不动卡片本体，密集列表不"花"
  • 需要改 sidebar 左 padding 让红条有显示空间
  • 动画长时间可能视觉疲劳

B5 · "新" 字红 chip 语义最强

红色单字"新" chip，左低右高渐变红，无数字。waiting 仍橙色 "⏸ 等你"。

  • 语义最直接（中文母语用户秒懂）
  • chip 形式与 model/ctx badge 视觉风格统一
  • chip 色块面积大，占视觉权重
  • 红 chip + 橙 waiting badge 同行时颜色密度高

B6 · 标题前 ▍ 红窄条（极致简）

未读 session 标题前出现 3×14px 红色窄条 + 微脉冲。waiting 时变橙色。无任何额外 badge / chip / dot。

  • 视觉最干净，整个右侧 badge 区不变

  • 跟 IDE 改动指示风格一致（Git 增删条）
  • 波动较小，急切场景下可能不够醒目
