按钮风格 v3 · 4 个新备选 不要再糖果了

用户反馈:当前软糖胶囊"丑" — 主因是荧光绿(#34d399→#10b981)+ 紫粉渐变(#a371f7→#db61a2),整体像甜品店。 新一版 4 个备选都去渐变 / 去荧光 / 去糖果,聚焦专业 dev 工具感。底部贴当前糖果版作为对比基准。

D · GitHub Primer ★ 推荐 · 最稳
参考 GitHub 官方按钮(Primer Design System)。
• 主按钮 #238636(GitHub 深绿,不亮但权重足)
• 圆桌按钮 #1f6feb(GitHub 蓝,中性而不娇)
• 其他按钮 ghost(rgba 5% 半透白) + 1px 边框
• 圆角 6px(矩形,非胶囊),高 28px
✓ 程序员一眼熟悉✓ 4 主题最适配✓ 不抢戏不显土
· 略保守
E · Linear 风 精致 · 略带光泽
参考 Linear 应用 toolbar 按钮。
• 主/圆桌都用 Linear 标志性紫蓝 #5e6ad2(冷静而不冷漠)
• 内层 inset 高光 rgba(255,255,255,0.07) 营造质感
• 其他按钮深灰底 + 边框,hover 提亮
• 圆角 7px,高 30px
✓ 最精致✓ 主色品牌一致✓ 微光泽不浮夸
· 主+圆桌同色,要靠图标区分
F · 黑白主义 极简 · 反差最大
参考 Vercel / shadcn/ui。完全去彩色。
• 主按钮 纯白底 + 黑字(暗色背景下视觉权重最高)
• 其他按钮:1px 灰边 + 透明底,hover 微亮
• 圆桌按钮和主按钮同款白底(双 hero),靠 hover 区分
• 圆角 6-8px,icon-only 按钮做成完美圆形
✓ 高级感最强✓ 永不过时✓ 4 主题完美适配
· 圆桌不够"圆桌特色"· 太克制可能显冷漠
G · Liquid Glass macOS 玻璃
参考 macOS Sonoma / Tahoe 控件。
• backdrop-filter blur 玻璃质感
• 主按钮:Apple 系统绿(#30d158)+ 内层高光
• 圆桌:Apple 系统蓝(#007AFF)
• 其他按钮:5% 白底半透 + 1px 高光边
• 高 32px,圆角 9px
✓ 最有质感✓ 苹果生态熟悉✓ 高级
· 渲染开销大· 偏苹果系
H · Anthropic 暖橙 品牌色 · Claude 同款
用 Anthropic 品牌橙 #d4a574(Claude logo 颜色)做主按钮。
• 主按钮:橙色填充 + 黑字(权重最高)
• 圆桌:橙色 ghost(rgba 15%)+ 边框(同色 40%)
• 其他按钮:深灰 + 1px 边,hover 提亮
• 圆角 6px,高 28px,克制紧凑
✓ 与 Claude logo 同色 = 品牌呼应✓ 暖色 = 不冷✓ 克制紧凑
· Anthropic 橙在 aurora 主题里可能略冲突
当前 v0.8.4 · 软糖胶囊 就是这个被吐槽
• 荧光绿渐变 #34d399 → #10b981(过亮)
• 紫粉渐变 #a371f7 → #db61a2(廉价)
• 圆角 999px 胶囊(大圆角)
· 荧光感· 紫粉糖果味· 不像 dev 工具

推荐顺序

1. D · GitHub Primer — 最稳。程序员一秒认得是"严肃工具",4 主题适配最好。圆桌按钮蓝色不抢戏,新建按钮深绿权重足。
2. H · Anthropic 暖橙 — 品牌呼应。Hub 用 Claude 服务,新建按钮和 launcher 海报里 Claude 头像同色,视觉一致性最强。
3. F · 黑白主义 — 高级感天花板。但圆桌按钮失去"特色 hero"地位,需要靠图标区分两个白按钮。
4. E · Linear — 精致带光泽。Linear 紫蓝 #5e6ad2 很高级,但主按钮和圆桌按钮同色易混。
5. G · Liquid Glass — 苹果系玩家最爱。但渲染开销大且和 Hub 暗色"工具感"略偏苹果系生态。
