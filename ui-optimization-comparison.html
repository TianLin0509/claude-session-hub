优化总结 & 优先级建议

按投入产出比和用户感知度排序

# 优化点 影响范围 投入 优先级 说明
01 会话卡片状态可辨性 sidebar 核心交互 中 P0 用户最频繁操作的区域，状态可见性直接影响效率
02 侧边栏头部重构 sidebar 头部 中 P0 新建/搜索是最高频操作，减少一步可大幅提升效率
08 微交互与过渡动画 全局 低 P1 纯 CSS 改动，投入小但体验提升显著
05 浮动输入栏增强 终端浮栏 低 P1 加模式标签+字符计数，改动小
03 终端头部信息重构 终端头部 低 P1 CSS+少量 JS，模型版本显式可见
07 紧凑/舒适双模式 sidebar 全局 中 P2 需要两套间距变量，但效果明显
04 空状态页引导增强 终端区域 低 P2 仅新用户受益，但改动小
06 预览面板头部优化 预览面板 低 P2 锦上添花，文件类型标签实用
建议实施路径：P0（01+02）为第一轮，解决最核心的会话管理和操作效率问题；P1（03+05+08）为第二轮，打磨交互细节；P2（04+06+07）按需推进。预计全部完成约 2-3 个工作日。
